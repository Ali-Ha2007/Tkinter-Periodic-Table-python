# Interactive Periodic Table with Tkinter 
### About the project

This project is an interactive periodic table built in Python using Tkinter. The program allows users to click on different chemical elements and learn about atoms valence electron, mass, symbol, atomic number and type.
Users are able to combine different elements together.

The program has a seperate JSON file to store information about the elements. elementChange class is used to determine a metallic character of different elements and is then importet into the main program

### Features 

* Buttons for each Element.
* An add element button.
* A remove element button.
* Different color depending on element type.
* Seperate information for lanthanides and actinides.
* The ability to combine different elements and calculate the mass
